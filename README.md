🍔 Quite Bite
Overview

Quite Bite (internally named Tasty Treat Express) is a full-stack online food ordering platform built to provide a scalable, efficient, and user-friendly experience for customers and restaurant owners alike.

Developed using Spring Boot (Java) with a responsive Thymeleaf-based frontend, this application allows users to browse menus, select dishes, and place orders easily, while giving restaurant administrators the tools to manage menus and orders effectively.

The system was developed following Agile methodology, focusing on modular architecture, maintainability, and a smooth ordering flow.

🧩 Features

🍕 Interactive UI: Built with Thymeleaf templates, HTML, and CSS for an intuitive user experience.

🛒 Seamless Ordering: Users can browse menus, add items to cart, and place orders with ease.

🏪 Restaurant Management: Admins can add, update, or remove food items and view all customer orders.

⚙️ Scalable Backend: Spring Boot and MySQL ensure reliability and performance.

🔄 Agile Development: Built iteratively for continuous improvement and scalability.

🛠️ Tech Stack
Layer	Technologies

Backend	Java, Spring Boot
Database	MySQL
